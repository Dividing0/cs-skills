# Primary-source starting points

- [Manning, Raghavan and Schuetze, Introduction to Information Retrieval](https://nlp.stanford.edu/IR-book/html/htmledition/irbook.html)

Use these as sources, not automatic proof of the task's claim. Pin the applicable version, theorem, protocol or section when reporting a result. Resolve moving documentation to the target version where possible. Prefer the original paper or official documentation for technical claims; distinguish a source's result from an inference about the user's system. Retrieve relevant content before attributing a claim. Tool/API pages can change and must be checked when applied.
